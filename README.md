## Technical Stack & Lab Requirements

- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`), structured forms, unique IDs, accessible attributes, and responsive meta tags on every page.
- **CSS3**: Managed entirely via external stylesheet (`css/style.css`).
- **Horizontal CSS Float Navigation**: Standard `<ul>` / `<li>` menu styled with `float: left;` and active page highlighting across primary and secondary navigation rows.
- **CSS Float Property**: Demonstrated in the profile hero section (floated image with text wrapping) and multi-column contact/gallery card layouts.
- **CSS Clear Property**: Layout clearfix (`clear: both;` and `clearfix::after`) applied after floated elements to prevent container collapse.
- **Image Gallery (Float Layout)**: 5 floated gallery cards with responsive arrangement and hover zoom transitions.
- **Responsive Web Design**: Pure CSS media queries ensuring clean wrapping across desktop, tablet, and mobile views.
- **GitHub Pages Ready**: Relative asset paths (`css/style.css`, `images/profile.jpg`, relative HTML links) for standard static hosting.
